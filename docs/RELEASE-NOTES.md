# v1.4.0 Release Notes

> 主要变化范围：v1.2.2 → v1.4.0

## ✨ 新功能

### 🤖 AI 智能助手（新增）
- 全新对话式 AI 助手：多会话管理、流式对话、会话持久化
- 支持多模型提供商，动态获取模型列表
- Markdown 技能系统：内置技能 + 自动/手动触发激活
- 内置数据工具：持仓查询、交易记录、期权持仓等函数调用
- 推理过程与工具调用卡片展示、代码高亮
- 新增 6 个投资分析技能（技术指标、基本面分析等）
- 新增「芒格视角」技能：用芒格的思维框架分析公司与投资组合（触发词：芒格视角 / 芒格）

### 💰 现金存取
- 交易记录支持「存入现金 / 提取现金」操作（复用 `$CASH-*` 现金持仓机制）
- 提取现金超额校验（不能超过现金余额）

### 🎨 主题与设置
- 深色 / 浅色 / 跟随系统 主题支持（CSS 变量）
- 设置页新增「恢复出厂设置」：清空全部数据并还原默认

## 🚀 行情数据
- 新增东方财富（East Money）作为美股行情的免登录主数据源，带提供商回退链
- 雪球：一键登录 + Cookie 粘贴流程（修复登录窗口关闭竞态问题）
- 修复指数行情获取

## 📊 统计分析
- 整体统计 Tab 新增「个股明细」表格
- 修复：已清仓股票的盈亏计算（此前漏算 OPEN 建仓成本，导致清仓后显示盈利）
- 修复：个股明细排除已清仓股票（与市场统计口径一致）
- 总盈亏前移除货币符号，+/- 不再出现在货币符号后
- 显示行情数据更新时间；汇率卡片新增 HKD/CNY 汇率显示

## 📝 期权管理
- 导入 CSV 支持英文（IBKR 风格）字段名，表头匹配大小写不敏感
- 导入边界检测：平仓记录找不到对应开仓记录时拒绝插入，避免数据不一致
- 修复：纯 `C` 代码（买回平仓）未被识别为平仓，导致已平仓合约仍显示 active
- 修复：导出→清除→重新导入后开仓匹配失败（导出负数量的绝对值处理）

## 🗂 持仓 / 交易记录
- 持仓管理和交易记录记住上次「按账户」的选择（重启后自动恢复）

## 🔧 其他
- 窗口默认不再最大化启动
- 全量升级前后端依赖至最新版本；锁定 Rust 1.97.1、要求 Node ≥ 26
